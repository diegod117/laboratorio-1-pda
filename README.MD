# Sitio de Proyectos - Mish

Sitio web colaborativo que reúne los proyectos personales de los integrantes
del grupo: Johann Cortes Farias, Diego Cortes Toro, Martin Zepeda Puelles. Construido como parte del
Laboratorio 1 de Programación de Aplicaciones, usando Git y GitHub de forma
colaborativa.

## Estándares de diseño

- **Paleta de colores:** `#1A1A2E` (fondo), `#0F8B8D` (acento), `#F5F5F5` (texto sobre fondo oscuro), `#FFFFFF` (fondo de tarjetas)
- **Tipografía:** títulos → Poppins (600-700), texto → Inter (400)
- **Estructura de tarjeta:** título arriba, imagen al centro, descripción abajo, tecnologías usadas al final
- **Clases CSS comunes:**
  - `.project-card` — contenedor de cada sección
  - `.project-title` — título del proyecto
  - `.project-image` — imagen o placeholder
  - `.project-description` — texto descriptivo
  - `.project-tags` — contenedor de tecnologías
  - `.tag` — cada tecnología individual

## Estructura del repositorio

- `index.html` — página principal con las secciones de todos los integrantes
- `styles.css` — estilos compartidos según los estándares de diseño definidos arriba
- `README.md` — este documento
